# Формат открытого пакета данных TH01 (`TH01OPEN`)

Порт не читает файлы никакой конкретной игры. Вместо этого он читает простой,
полностью документированный контейнер, который вы собираете сами из своего контента.
Этот документ — спецификация. Реализации:

- сборка и разбор: `scripts/pack_th01_data.py` (Python, только стандартная библиотека);
- чтение в движке: `highly-responsive-prayers/th01/hrp_pkg.c`;
- независимый разбор в тестах: `tests/test_th01.py` и `tests/native/th01_pkg.c`.

Все числа — **little endian**. Версия формата: **1**.

## 1. Заголовок (16 байт)

| Смещение | Размер | Значение |
| --- | --- | --- |
| 0x00 | 8 | сигнатура `TH01OPEN` |
| 0x08 | 2 | версия формата = 1 |
| 0x0A | 2 | число секций |
| 0x0C | 4 | зарезервировано, 0 |

## 2. Секции

Каждая секция:

| Поле | Размер | Значение |
| --- | --- | --- |
| type | 4 | тип секции |
| length | 4 | длина полезной нагрузки в байтах |
| payload | length | содержимое |
| padding | 0..3 | нули до границы 4 байт |

Типы:

| type | Название | Назначение |
| --- | --- | --- |
| 1 | STAGES | список этапов (обязательная секция, хотя бы один этап) |
| 2 | PALETTE | до 32 цветов RGBA (опционально) |
| 3 | TEXT | текстовые строки `КЛЮЧ=значение` (опционально) |
| 4 | MUSIC | зарезервировано; движок принимает и игнорирует секцию |

Неизвестные типы пропускаются. Неизвестная версия, обрезанная секция и «невозможные»
параметры этапа — ошибка разбора: движок не применяет половину данных, а пишет причину в лог
и играет встроенный набор.

## 3. Секция STAGES

```
u16 stage_count
далее для каждого этапа:
    u8  type          0 = карточный этап, 1 = этап босса
    u8  rows          число строк карточного поля
    u8  cols          число столбцов карточного поля
    u8  orb_speed     скорость орба в 1/4 пикселя за кадр (20 = 5 px/кадр)
    u8  boss_pattern  0 = sweep, 1 = orbit, 2 = stream
    u16 boss_hp       HP босса (для типа 1 — обязательно > 0)
    u16 time_limit    предел времени в кадрах (0 = без предела, 3600 = 60 с)
    u8  reserved      0
    char name[24]     название, UTF-8, дополнено нулями
    u8   cells[rows*cols]  типы карточек, построчно (только для типа 0)
```

Типы карточек: `0` пусто, `1` обычная (1 удар), `2` прочная (2 удара), `3` каменная
(не разрушается), `4` силовая (после разрушения роняет улучшение).

Ограничения: `rows * cols` ≤ 160, этапов ≤ 20, `boss_hp` от 1 до 65535.

## 4. Секция PALETTE

```
u16 count        (<= 32)
u32 colors[count]  0xAABBGGRR: байт 0 = R, байт 1 = G, байт 2 = B, байт 3 = A
```

## 5. Секция TEXT

Последовательность записей `u8 length; char[length]`. Первая запись вида
`TITLE=<название>` попадает в лог и может показываться на экране.

## 6. Пример `content.json`

```json
{
  "title": "my set",
  "stages": [
    {
      "type": "card",
      "name": "SHRINE GATE",
      "rows": 5,
      "cols": 12,
      "orb_speed": 20,
      "cells": [
        "############",
        "##..####..##",
        "TT########TT",
        "#####PP#####",
        "#..SS##SS..#"
      ]
    },
    {
      "type": "boss",
      "name": "KEEPER OF THE GATE",
      "boss_hp": 900,
      "boss_pattern": "sweep",
      "time_limit": 3600
    }
  ],
  "palette": ["#dc506e", "#b4551e", "#5adc96", "#ffffff"],
  "text": ["NOTE=edit and repack with pack_th01_data.py"]
}
```

Символы клеток: `.` пусто, `#` обычная, `T` прочная, `S` каменная, `P` силовая.

## 7. Команды

```bash
python3 scripts/pack_th01_data.py --emit-example my-content   # шаблон content.json
python3 scripts/pack_th01_data.py --source my-content --output th01open.dat
python3 scripts/pack_th01_data.py --verify th01open.dat       # независимый разбор
```

`--verify` печатает версию, список секций, заголовок и сводку по этапам. Сборщик сам
прогоняет результат через разборщик: если пакет не читается, файл считается неудачным.

## 8. Куда положить файл

```
sdmc:/switch/th01/th01open.dat
```

Если файла нет, повреждён или имеет неподдерживаемую версию — порт пишет причину в
`sdmc:/switch/th01/th01.log` и играет встроенный процедурный набор (8 этапов).

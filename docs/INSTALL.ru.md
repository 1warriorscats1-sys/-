# Установка из своей Steam-копии

## Главное ограничение

Это **набор инструментов**, а не самостоятельный открытый движок, как в порте TH06.
Steam даёт PC-файлы игры, но не закрытый GameMaker Switch runtime и не право распространять его.
В репозитории нет игры, NSP/NRO, SDK, ключей или готового `main`; инструмент их не скачивает.

Для запуска нужна **отдельно и законно полученная совместимая Switch-сборка Санаэ**:
рантайм 2024.14.3.260, title ID `010000000005A1E1`, с патчами совместимости.
Если у человека только Steam-версия — он сможет подготовить данные, но запуск на Switch
этим набором в одиночку не обеспечивается. Для сценария «только Steam и больше ничего»
понадобится разрешённая к раздаче сборка от правообладателей либо другой, независимый движок.

## Самый простой путь

1. На GitHub нажми **Code → Download ZIP** и распакуй исходники в доступную для записи папку.
2. Установи Python **3.10+** с python.org. В Windows включи **Add Python to PATH**.
3. Steam → Санаэ → Управление → **Просмотреть локальные файлы**.
4. Закрой PC-игру и приостанови обновления. В открытой папке должны быть `data.win` и `audiogroup*.dat`.
5. В Windows дважды нажми **Prepare-SANAE.cmd** и выбери эту папку.
   Можно перетащить папку игры на `.cmd`.
6. Дождись сообщения **Prepared**. В папке инструментов появится `sdcard-pack`.
7. Закрой Санаэ на Switch через **HOME → X**. Сделай резервную копию старых файлов `romfs`.
8. Из `sdcard-pack` перенеси **папку atmosphere** в корень SD с объединением папок.
   Не переноси саму папку `sdcard-pack` как дополнительный уровень.
9. Запусти уже установленную совместимую Санаэ. Проверь музыку, голоса, сохранение,
   выход, повторный запуск и возврат в титул.

**Работающий патч выхода оставь на месте. NSP переустанавливать не нужно.
Сохранения и существующий `exefs` не удаляй.** Подготовщик меняет только копию данных на PC,
а не установленную программу или сохранения на SD.

На Linux/macOS:

```sh
./prepare-sanae.sh "/путь/к/Steam/steamapps/common/Санаэ"
```

На любой системе через Python (если нет окна выбора папки):

```sh
python scripts/prepare_sd.py "D:\SteamLibrary\steamapps\common\SANAE" --output sdcard-pack-2
```

Существующая папка результата не перезаписывается. Для повторного запуска укажи новое
имя через `--output`. Исходники Steam программа читает, но не изменяет.

## Что происходит с data.win

Простого переименования в `game.win` недостаточно. Формат комнат и аудиогрупп в PC-версии
отличается от того, который ожидает Switch-рантайм. Подготовщик автоматически:

1. Проверяет, что это поддерживаемая VM-версия Санаэ, а не другая игра или YYC.
2. Локально конвертирует структуры комнат и аудиогрупп.
3. Адаптирует необязательные вызовы Steamworks, которых нет на Switch.
4. Проверяет полученный `game.win` и копирует внешние аудиогруппы.
5. Создаёт дерево SD, инструкцию, журнал и контрольные суммы.

Это адаптация необязательных Steam API для другой платформы, а не получение игры
без покупки и не патч защиты PC-EXE. Новая версия игры из Steam может потребовать
изменений конвертера; при ошибке программа останавливается, а не выдаёт непроверенный пак.

Если не хватает аудиофайла — проверь целостность своей игры через Steam. Пустая аудиогруппа 1
в известной версии необязательна; группы со звуками должны присутствовать.

**Результат содержит твою копию игры. Не выкладывай `sdcard-pack`, `game.win`, аудиофайлы
или локально созданный ZIP с рантаймом на GitHub.** Для отчёта об ошибке достаточно текста ошибки,
версии игры и контрольных сумм, без прикрепления самой игры.

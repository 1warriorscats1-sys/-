# `-` — порт-тулзы и экспериментальные открытые порты

Репозиторий содержит экспериментальные, **source-only** инструменты и порты homebrew
для Nintendo Switch. Никаких данных игр, проприетарных рантаймов, SDK, ключей и
загрузок из сети: всё собирается из исходников открытым тулчейном.

## Активный порт в этой ветке

**[TH01 — открытый порт (карточные этапы + боссы)](highly-responsive-prayers/README.md)**

Оригинальная реализация игровой структуры первой части PC-98 (поля карточек, чередующиеся
с боями боссов), написанная с нуля на C: свой рендерер, свой процедурный контент, свой
синтезатор. Читает опциональный открытый пакет данных с SD-карты
(`sdmc:/switch/th01/th01open.dat`), который вы собираете сами.

```bash
python3 -m unittest discover -s tests -v        # публичные тесты (stdlib)
python3 scripts/test_th01_native.py --sanitize  # нативные тесты (ASan + UBSan)
python3 scripts/build_th01.py --target headless # сценарии симуляции
python3 scripts/build_th01.py --target host     # кадры, WAV и preview-GIF
python3 scripts/build_th01.py --target switch   # th01.nro (devkitPro/devkitA64)
```

Документация: [формат данных](docs/TH01_DATA_FORMAT.md),
[про оригинальные данные и границы допустимого](docs/TH01_ORIGINAL_DATA.md),
[установка на консоль](highly-responsive-prayers/TH01_INSTALL.txt).

## Границы

- Мы не распространяем данные, графику, музыку и торговые марки правообладателей и не
  обходим DRM. Порт принципиально работает со своим открытым форматом контейнера.
- Nintendo SDK не используется: только открытые devkitA64 и libnx.
- Статусы честные: сборки проверяются тестами и CI, но **не проверены на реальной консоли**.

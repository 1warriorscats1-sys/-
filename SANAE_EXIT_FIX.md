# SANAE — исправление выхода (кандидат для проверки на Switch)

Для SANAE's Sylphid Breeze, title ID `010000000005A1E1`,
рантайм 2024.14.3.260 из исходной ветки saekaze/th8test.

## Установка

1. Полностью закрой игру через HOME → X.
2. Если на SD уже есть `atmosphere/contents/010000000005A1E1/exefs/main`,
   сохрани его копию на компьютере для отката.
3. Распакуй папку `atmosphere` из `SANAE_exit_fix.zip` в корень SD,
   объедини папки и согласись на замену `exefs/main`.
4. Запусти игру, измени настройку/сделай сохранение и выбери выход из игры.
5. Проверь, что появился HOME без сообщения об ошибке, затем запусти игру
   снова и проверь сохранение. Отдельно проверь «Вернуться в титул»:
   эта команда не должна закрывать приложение. Повтори выход несколько раз.

Не удаляй сохранения. Не заменяй `game.win` и аудиофайлы.
Переустанавливать NSP не нужно: ZIP заменяет только исполняемый `main`.
Не используй этот main для других игр или других версий рантайма.

Откат: закрой игру и восстанови предыдущий `exefs/main`; если до установки
его не было, удали добавленный файл (не всю папку contents).

## Что изменено

Старый патч вызывал C `exit(0)` прямо из `game_end`, не завершая
обработчик. Новый код только ставит отдельный флаг выхода и восстанавливает
исходный стек обработчика. В начале следующей итерации основного цикла
выполняется прежний guarded commit сохранения и вызывается
`nn::oe::ExitApplication`, разрешённый через импорт `nn::ro::LookupSymbol`.
Если разрешение символа не удалось, указатель NULL или SDK неожиданно вернул
управление, используется системный `ExitProcess` (SVC 7), а не C `exit`.
Этот запасной путь не равнозначен подтверждённому штатному выходу через oe.

Флаг размещён за прежним BSS; увеличены NSO BSS и граница BSS в MOD0.
Ни одно существующее поле данных не занято под флаг. Меняется только main;
SDK и таблицы его импортов остаются прежними. Работающие вставки сохранения
и пять перехватов CloseFile побайтно совпадают с исходным патчером.
Патчи возврата в титул, аудиогрупп и deprecated builtins сохранены.

## Проверка и ограничения

11 локальных unittest-тестов, включая исполнение ARM64-вставок в Unicorn:
обычный цикл, отложенный выход, восстановление стека, два адреса загрузки,
ошибки LookupSymbol, commit с/без смонтированного сохранения, границы сегментов
и отказ при несовпадении инструкций. Вызовы SDK в эмуляторе подменены:
это не проверка реальной работы сервисов Switch. Экспорт ExitApplication
подтверждён в комплектном SDK, но разрешение символа и закрытие через HOME
ещё требуют проверки на устройстве. Исправление не выдаётся за проверенное
на настоящей консоли. Если ошибка останется, нужен её код и свежий crash report.

## Повторная сборка

```
python3 scripts/fetch_sanae_inputs.py
python3 -m venv .venv
.venv/bin/pip install -r requirements-patch.txt
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python scripts/build_exit_patch.py
```

Патчер принимает только исходный main с SHA256
`dcd5b9fc9ca50bf61f781a6a381c2f149ba97f82f395b94fe8f89d6c05ef3a2c`.
ZIP собирается без ключей и без переупаковки NSP. Загруженный отдельно
`SANAEs_Sylphid_Breeze.nsp` остаётся старой исходной сборкой и не содержит
этого исправления сам по себе.
